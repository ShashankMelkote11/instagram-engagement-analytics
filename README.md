# Instagram Engagement Analytics & Prediction

## 📌 Overview

This project analyzes influencer content performance and builds a machine learning model to predict high-performing posts.

It introduces a custom metric — **Engagement Quality Index (EQI)** — to capture engagement quality beyond traditional metrics like likes and engagement rate.

---

## 🎯 Objectives

* Identify key drivers of influencer engagement
* Differentiate between engagement quality vs quantity
* Predict high-performing content using machine learning

---

## 🧠 Key Features

* Feature engineering (virality score, saves-to-reach, comment density)
* Machine learning models (Logistic Regression, Random Forest)
* Custom metric: **EQI (Engagement Quality Index)**
* Threshold tuning for real-world applications

---

## 📊 Key Insights

* Saves (intent) and shares (distribution) are the strongest predictors
* Caption length, posting time, and media type have minimal impact
* EQI outperforms traditional engagement rate

---

## ⚙️ Tech Stack

* Python (Pandas, NumPy, Scikit-learn)
* Visualization (Matplotlib, Seaborn)
* Power BI (for dashboard)
